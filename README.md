# Sales-Data-Analysis
Sales Data Analysis using Microsoft Excel
## Project Overview
This project analyzes sales data using Microsoft Excel to identify sales trends, business performance, and revenue insights.

## Objectives
- Analyze total sales and revenue.
- Identify top-performing products.
- Analyze monthly sales trends.
- Compare regional sales performance.
- Identify top-performing customers.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Interactive Dashboard

## Key Analysis
- Total Revenue
- Total Orders
- Top-Selling Products
- Monthly Sales Trends
- Regional Performance

## Project Files
- Professional Sales Dahboard.xlsx – Excel analysis and dashboard.
- Dashboard_Screenshot.png – Dashboard preview.

## Conclusion
This project demonstrates how Excel can be used to transform raw sales data into meaningful business insights and support data-driven decision-making.
